# Magic Circle Charging Screen

`MagicCircle/Red.html`을 오프라인 Android 화면 보호기로 실행합니다.

## 사용

1. 앱을 설치하고 실행합니다.
2. **충전 화면 보호기 설정 열기**를 누릅니다.
3. 화면 보호기로 **마법진 충전 화면**을 선택합니다.
4. 실행 조건을 **충전 중**으로 설정합니다.

충전 중 기기가 유휴 상태가 되면 시스템이 화면을 표시합니다. 충전이 해제되거나 사용자가 화면을 조작하면 기존 잠금화면으로 돌아갑니다.

## 빌드

```powershell
.\gradlew.bat assembleDebug
```
