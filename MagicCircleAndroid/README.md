# Magic Circle Charging Animation

`MagicCircle/Red.html`을 바탕으로 새로 구성한 애니메이션을 인터넷 없이 실행하고, 충전기를 연결할 때 접근성 오버레이로 최대 7초 동안 표시합니다.

## v1.10 — 첨부 도안 118개 앱 통합

표시 버전 **1.10**, 설치 번호 **13**. 기존 55종을 유지하고 자료집 117개 + 추가 기준 선화 R01을 별도 ID로 추가합니다. 총 **173개 기본 선택 항목**이며 같은 모티브의 색상·세부 변형도 포함한 수치입니다.

- 앱의 **첨부 도안** 탭에서 118개를 확인합니다. `C03`, `W03`, `R01`처럼 번호로 검색할 수 있습니다.
- 한국어·일본어·영어, GIF/PNG/JPG 가져오기, 개인 파일 삭제, 기본 도안 숨기기·복원을 유지합니다.
- 충전 화면은 압축 SVG를 기기 안에서 풀어 표시합니다. SVG 안에 저해상도 PNG를 삽입하지 않았습니다. 목록용 PNG 썸네일과 실제 충전용 벡터는 구분됩니다.
- 구조를 유지하기 위해 연결된 원·별·나무는 고정합니다. 별도 입자와 부드러운 등장·퇴장만 적용하며, 붙어 있는 도형을 임의로 분리해 회전시키지 않습니다.
- 불러오는 시간도 기존 **연결 시점부터 최대 7초** 예산에 포함됩니다. 분리하면 닫히고 재연결하면 새 화면으로 시작합니다. 기기 잠금을 해제하지 않습니다.
- 이미지와 글꼴을 인터넷에서 받지 않습니다. `INTERNET` 권한, 새 외부 라이브러리, 유료 API를 추가하지 않습니다.

### 도안 품질에 대한 정확한 구분

C03/R01의 수치 기반 원·곡선·공유 꼭짓점은 그대로 보존합니다. 다른 도안은 기존 검토용 벡터의 닫힌 색상 윤곽을 앱에 통합합니다. 용량과 실제 표시 시간을 줄이기 위해 중첩 RGB 농도층을 정리하며, 유지한 곡선 좌표는 변경하지 않습니다. 단계 수는 최종 `collection/pack-report.json`에 기록합니다. RGB 층이 합성되며 색의 미세한 경계는 원본과 차이가 있습니다.

**118개 모두를 원본과 완전히 동일한 초정밀 수작업 원화로 완성했다는 뜻은 아닙니다.** 일부 참고 도안은 약 180px이고 제목·발광이 선을 가리고 있습니다. 판독 불가능한 룬이나 숨은 도형을 임의로 복원하지 않습니다. 세계수의 잎·꽃·구름은 모든 개체가 독립된 레이어로 분리된 것은 아닙니다. 편집할 벡터는 `app/src/main/assets/collection/art/*.svgz`를 gzip으로 풀면 얻을 수 있습니다.

A04/A05의 도안과 무관한 세로 구분선은 제거했습니다. A 그룹의 하단 제목은 실제 도형과 붙어 있어 안전하게 분리하지 못했으며 **그대로 남아 있습니다**. 이 제한은 해당 도안의 앱 설명에도 표시합니다. U04의 예시 숫자를 지운 중앙에는 실제 배터리 잔량을 표시합니다. 업데이트 전 모든 기존 항목을 숨겨 무선택 상태였다면 새 항목을 자동 적용하지 않습니다.

## 이전 v1.9 기록 — 내 파일과 충전 재연결 보완

이번 개발판은 **1.8 복원판을 기반으로 한 v1.9 (`versionCode=12`)**입니다. 기존 55종과 한국어·일본어·영어를 유지합니다. 앞으로 배포할 때는 표시 버전과 `versionCode`를 모두 올립니다. 예전의 이미지 표시 방식 v1.9(code 10)와는 다른 업데이트입니다.

설치 파일: [MagicCircleCharging-v1.9-debug.apk](releases/MagicCircleCharging-v1.9-debug.apk). 기존 복원판과 서명이 같으므로 앱을 삭제하지 않고 업데이트할 수 있습니다. 실제 설치는 기기에서 확인해야 합니다.

1. **파일 가져오기**에서 기기의 GIF·PNG·JPG/JPEG 파일을 고릅니다. 가져온 파일은 바로 선택되며 **내 파일**에서 다시 찾을 수 있습니다.
2. **7초 미리보기**로 확인합니다. 다른 항목은 카드를 선택한 뒤 **이 마법진 적용**을 누릅니다.
3. GIF는 연결마다 첫 프레임부터 재생합니다. 정지 사진은 원래 비율을 유지하면서 부드럽게 나타나 조금 확대된 뒤 사라집니다. 로딩 시간을 포함해 연결 후 최대 7초이며, 충전기를 빼면 즉시 닫습니다.
4. **선택 항목 삭제**는 확인창을 거칩니다. 가져온 파일은 앱의 복사본만 지우며 휴대폰 원본은 건드리지 않습니다. 기본 마법진은 목록에서 숨기고 **기본 마법진 복원**으로 되살립니다. 전부 제거하면 충전 연출을 표시하지 않습니다.

파일은 앱 전용 **자동 백업 제외 폴더**에 복사됩니다. 인터넷 권한·저장소 전체 접근 권한·외부 업로드·유료 API를 추가하지 않았습니다. 원본을 이동해도 앱 복사본은 유지되지만, 앱 삭제/데이터 초기화 시 가져온 목록과 복사본은 없어집니다. 삭제 도중 저장장치 오류가 나면 완료로 표시하지 않고 남은 복사본 정리를 다음 앱 실행 때 재시도합니다.

메모리 보호를 위해 파일당 20 MiB, 가로·세로 각각 4,096px 및 총 1,600만 화소까지 허용합니다. GIF는 캔버스 400만 화소·300프레임·캔버스×프레임 합계 1억 2천만 화소 제한이 함께 적용됩니다. 큰 GIF는 휴대폰용으로 줄여 가져오세요. 목록에는 작은 정적 썸네일을 사용합니다. HEIC·WebP·동영상은 이번 버전에 포함하지 않았습니다.

### 재연결 수정과 확인 범위

이전 서비스는 WebView의 첫 프레임 확인 알림이 와야 애니메이션을 시작했습니다. 이 알림이 늦거나 누락되면 페이지가 준비돼도 시작하지 않는 경로가 있었습니다. 이제 페이지 준비 후 JavaScript를 시작하고, 실제 시작 여부를 최대 3초 동안 제한적으로 확인합니다. 프레임 확인은 진단 기록으로만 사용합니다. 매 연결마다 새 WebView와 새 실행 ID를 만들며, 이전 실행의 지연 응답·종료 예약은 무효화합니다. 화면이 꺼질 때는 재생을 끝내 절전 후 오래된 화면이 다시 나타나지 않게 했습니다. 잠금을 해제하지 않습니다.

**현재 PC에 ADB 기기가 없어 S26 실기기의 이번 재발 원인 및 수정 효과는 미확정입니다.** 코드의 시작 대기 경로는 보완했지만, 제조사 절전·화면 깨우기·접근성 서비스 유지 여부까지 해결됐다고 볼 수 없습니다. APK 설치 후 앱을 홈으로 보낸 상태와 잠금/화면 꺼짐 상태에서 각각 5회 물리적으로 재연결해 주세요. 재생 중 분리, 빠른 재연결, GIF/사진/기본 마법진, 비행기 모드도 확인합니다.

문제 재현 직후 읽기 전용 진단(배터리 상태 변경이나 로그 삭제 없음):

```powershell
.\selftest\device-charging-overlay.ps1 -Adb adb -DiagnosticsOnly
```

PC 검증(2026-09-15): Java 자체 테스트 4종, 55종 마법진/3개 언어/파일 목록 브라우저 검사, 실제 두 프레임 GIF의 재시작, 삭제·복원·빈 목록·손상 목록 보호, 오프라인·7초 제한·화면 폭 검사를 통과했습니다. `gradlew.bat --offline test lintDebug assembleDebug` 성공, lint 오류·경고 0건입니다. Gradle JUnit 테스트는 `NO-SOURCE`이므로 Java 자체 테스트를 별도로 실행했습니다. Android 파일 선택기·네이티브 디코더·실제 WebView 파일 연결과 기기 절전은 실기기 검증이 남아 있습니다.

새 정적 벡터 검토 자료는 아직 앱에 넣지 않았습니다. 기존 `design-studies/`와 1.8 복원 파일은 보존했습니다.

## 설치 및 최초 설정

이전 개발 기준인 **1.8 복원판** 기록: 과거 1.9의 원본 이미지 표시 변경은 Git 되돌리기 커밋으로 취소했으며, 이전 기록은 보존했습니다. 복원 APK는 `versionName=1.8`, `versionCode=11`로, 기존 1.9(code 10) 위에 동일 서명으로 업데이트할 수 있도록 설치 번호만 높였습니다. 기능·언어·기존 55종 디자인·충전 서비스는 1.8과 같습니다. 복원 당시 기기 연결이 없어 실제 설치는 확인하지 않았습니다.

Android는 작은 `versionCode`의 설치를 막기 때문에 과거 APK를 그대로 덮어쓰지 않습니다. [공식 앱 버전 문서](https://developer.android.com/studio/publish/versioning)를 따릅니다. 기존 앱을 삭제하거나 앱 데이터를 초기화할 필요는 없습니다. 1.9 전용 그림을 선택한 상태였다면 해당 ID는 1.8의 기본 디자인으로 처리되므로, 복원 후 원하는 1.8 디자인을 다시 적용하세요.

C03 정적 벡터 검토안은 `design-studies/C03/`에 분리해 보관하며, 사용자 확인 전에는 앱 목록·회전·충전 연동에 등록하지 않습니다.

복원 설치 파일: [MagicCircleCharging-v1.8-restore-debug.apk](releases/MagicCircleCharging-v1.8-restore-debug.apk). SHA-256: `1B3F7091DBD88FE8BCE6F84AC6CDE5F283E0472FA8214CDE15BC78DB2B6C50BC`.

1. `app-debug.apk`를 설치하고 앱을 한 번 실행합니다.
2. **접근성 서비스 설정 열기**를 누릅니다.
3. **마법진 충전 애니메이션**을 선택하고 허용합니다.
4. 사이드로드 보안 때문에 항목이 비활성화되면 앱 정보 화면의 오른쪽 위 메뉴에서 **제한된 설정 허용**을 먼저 선택합니다.

충전기를 연결하면 **연결 감지 → 충전 실행 → 마법진 → 완료** 순서로 한 번 재생되고 최대 7초 뒤 원래 화면으로 돌아갑니다. 재생 도중 충전기를 분리하면 즉시 종료되며, 다시 연결하면 처음부터 재생됩니다.

첫 화면 준비가 확인되면 재생을 시작하며, 로딩이 실패하면 즉시 원래 화면으로 돌아갑니다. v1.3~v1.6의 투명한 로딩 창은 S26에서 화면 준비 신호를 막는 문제가 확인되어 v1.7에서 제거했습니다.

v1.4에서는 중앙 팔망성·육망성의 선을 항상 완전히 연결하고, 원형 룬 문자를 360도 균등하게 배치했습니다. 과한 방사형 광선은 줄여 문양이 더 선명하게 보입니다.

앱 내부에서 한국어·일본어·영어를 선택할 수 있습니다. 마법 문양의 팔망성과 육망성은 회전하지 않습니다.

## v1.8 언어 선택과 환상의 서

앱 상단에서 **한국어 / 日本語 / English**를 누르면 즉시 언어가 바뀌고 자동 저장됩니다. 앱을 다시 열거나 충전기를 다시 연결해도 유지됩니다. 첫 실행 시 기기의 한국어·일본어·영어 설정을 따르며 그 밖의 언어는 영어로 시작합니다. 보관함·마법진 이름·설명·충전 문구·배터리 정보·미리보기 닫기 버튼에 함께 적용됩니다. 휴대폰 시스템이 표시하는 앱 이름과 접근성 설명은 기기의 언어를 따릅니다.

기존 13종에 **새 디자인 42종**을 더해 **총 55종**을 선택할 수 있습니다. 첨부한 세 컬렉션의 겹치는 문양은 정리하고, 구별되는 문양을 새 SVG 벡터로 구성했습니다. 이미지를 잘라 확대하지 않으므로 큰 태블릿에서도 선과 룬이 선명합니다.

- 천체: 달의 위상, 태양, 별자리, 은하, 시공간, 시간의 톱니바퀴
- 상징: 연금술, 생명의 지팡이, 치유, 천사의 날개, 봉인 사슬, 수호 결계
- 정령: 물, 불, 바람, 대지, 생명나무, 정령의 꽃, 연꽃, 눈꽃, 벚꽃
- 신비: 대현자의 핵, 전지의 눈, 중력, 무한의 고리, 원소의 조화

**환상의 서** 분류에서 새 문양을 모아 보거나 이름 검색으로 찾을 수 있습니다. 카드를 선택한 뒤 **7초 미리보기**로 확인하고 **이 마법진 적용**을 누르세요. 언어와 마법진은 서로 독립적으로 저장됩니다. 미리보기만으로 적용된 마법진은 바뀌지 않습니다.

문양은 고정하고 빛·입자만 느리게 움직입니다. 목록은 가까운 썸네일만 불러와 긴 컬렉션을 스크롤할 때 부담을 줄입니다. 외부 라이브러리, 다운로드 글꼴, 인터넷 권한, 유료 API를 추가하지 않았습니다.

추가 검증: `node selftest/languages.test.js`, `node selftest/new-circle-designs.test.js`, `node selftest/languages-browser.test.js`, 기존 `circle-browser.test.js`, Java `LanguageSelectionSelfTest`.

v1.8 PC 검증: 55종 렌더링·선택·검색, 3개 언어 전환, 미리보기와 적용 상태 분리, 오프라인 실행, 최대 7초 종료, 작은 화면·태블릿 배치, Java 자체 테스트를 통과했습니다. `test lintDebug assembleDebug --offline` 빌드 성공, Android lint 문제 0건입니다. APK 서명은 v1.7과 같아 기존 앱 위에 업데이트할 수 있습니다. 현재 USB 연결 기기가 감지되지 않아 v1.8 실기기 충전 재연결은 미검증입니다.

## v1.5 마법진 선택

앱을 열면 **마법진 보관함(魔法陣の書庫)**이 나옵니다. 대표 디자인 4종, 변형 8종, 기존 v1.4 디자인까지 총 13종을 선택할 수 있습니다.

2. **7秒プレビュー**를 누르면 7초 미리보기가 나옵니다. 미리보기만으로는 설정이 바뀌지 않습니다.
3. **この魔法陣を適用**(이 마법진 적용)을 누르면 저장됩니다. 다음 충전 연결부터 적용되며 앱을 다시 실행해도 유지됩니다.
4. **接続設定**은 충전 감지용 접근성 설정을 엽니다. **従来** 분류의 **月火星風**을 적용하면 기존 디자인으로 돌아갑니다.

## v1.6 화면 꺼짐 상태의 충전 재연결 수정

노트20 울트라(Android 13)에서 화면을 끈 뒤 충전 연결을 모의 시험했을 때, 충전 감지와 애니메이션 시작은 성공했지만 화면은 절전 상태에 남아 있었습니다. 기존 `FLAG_KEEP_SCREEN_ON`은 이미 켜진 화면을 유지할 뿐 꺼진 화면을 켜지는 않습니다.

충전 오버레이에 `FLAG_TURN_SCREEN_ON`을 추가해 새 연결마다 화면을 깨우도록 수정했습니다. 접근성 서비스의 창이므로 Activity 전용 `setTurnScreenOn()` 대신 창 옵션을 사용합니다. 잠금 해제·배터리 최적화 해제·추가 권한은 사용하지 않습니다. 최대 7초 종료, 충전 분리 시 즉시 종료, 매 연결마다 새 WebView로 재생하는 동작은 유지합니다. 연출 종료 후 화면이 다시 꺼지는 시점은 휴대폰의 화면 시간 제한 설정을 따릅니다.

회귀 테스트는 앱을 홈 화면으로 보낸 상태에서 3회 재연결하며, 화면 켜짐·오버레이 생성·JavaScript 시작·7초 후 제거·빠른 재연결·분리 시 제거를 확인합니다. `-ScreenOff`는 매번 화면을 끈 뒤 시험합니다. 테스트 후 배터리 모의 상태는 실제 상태로 복구됩니다.

```powershell
.\selftest\device-charging-overlay.ps1 -Adb adb -ScreenOff
.\selftest\device-charging-overlay.ps1 -Adb adb
```

ADB 모의 연결은 물리적 케이블·기기별 절전 정책의 모든 조건을 대신하지 않습니다. S26 울트라·탭 S11 울트라(Android 16)의 실제 케이블 연결과 보안 잠금 상태는 별도 확인이 필요합니다. 앱 설정에서 **강제 중지**하거나 접근성 권한을 끄면 감지하지 못합니다.

참고: [Android 공식 창 옵션 설명](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#FLAG_TURN_SCREEN_ON).

## v1.7 S26 울트라 반복 재생 수정

S26 울트라(Android 16)에서 v1.6의 실패를 재현했습니다. 충전 이벤트와 HTML 로딩은 정상인데 `postVisualStateCallback`(첫 화면 준비 알림)이 도착하지 않아 `LOADING` 상태에서 7초 후 종료되는 문제였습니다. 앱이 백그라운드일 때 완전히 투명한 WebView 루트를 준비 알림이 올 때까지 숨겨 두는 구조가 원인이었습니다.

WebView를 처음부터 그릴 수 있는 기본 불투명도로 유지하도록 불필요한 투명도 처리를 제거했습니다. 첫 화면 준비 확인과 7초 제한은 유지합니다. 재시도 타이머·추가 서비스·권한·외부 라이브러리는 추가하지 않았고, 디자인 선택과 기존 접근성 설정도 보존됩니다. Android 16에서 창 종류가 숫자 대신 이름으로 출력되는 차이도 기기 테스트에 반영했습니다.

수정 전 실제 기기 테스트는 페이지 로딩 후 재생 시작 확인에 실패했고, 투명도만 바꾼 비교 시험은 앱을 다시 열지 않은 채 5회 연속 재연결 및 자동 종료에 성공했습니다. 안내 문구와 마법진의 실제 화면도 각각 확인했습니다. ADB 모의 연결과 물리적 케이블 재연결은 별도로 구분해 검증해야 합니다.

v1.7 설치 후 사용자는 S26에서 케이블을 다시 연결해 시험했으며 정상으로 보인다고 보고했습니다. 최종 APK의 빌드·lint·기존 자체 테스트도 통과했습니다. 다만 이후 PC에서 USB 기기가 인식되지 않아, 계획했던 최종 화면 꺼짐 상태 5회 자동 시험은 완료하지 못했습니다. 이 항목과 다른 기기의 동작까지 검증 완료로 간주하지 않습니다.

기술 참고: [WebView 첫 프레임 조건](https://developer.android.com/reference/android/webkit/WebView#postVisualStateCallback(long,%20android.webkit.WebView.VisualStateCallback)), [Android의 alpha 0 그리기 생략 처리](https://android.googlesource.com/platform/frameworks/base/+/master/libs/hwui/RenderNode.h).
