# v1.23 — 사진 목록에서 머리카락만 교체

## 사용하는 순서

`VRM 등록 → 캐릭터 꾸미기 → 헤어 사진 선택 → 부위별 색상 → 이름·저장 → 배경화면 만들기`

- E 기본 / Hair02 두 헤어를 실제 캐릭터 사진 목록에서 선택한다. 선택한 사진에 금색 테두리와 체크 표시가 나타난다.
- 얼굴·눈·몸·의상·토끼 귀 등 기존 보호 파츠는 유지한다. Hair02 전체 캐릭터로 바꾸는 기능이 아니다.
- 머리와 홍채의 색상을 각각 팔레트·RGB·HEX로 지정한다. 헤어 모양을 바꾸어도 지정한 색상을 유지한다.
- 새 이름으로 저장, 기존 캐릭터 수정, 초안 복원, 이미지 레이어와 합성한 배경 작품 만들기를 지원한다.
- 작품은 선택 당시 헤어와 색상 사본을 저장한다. 보관함을 수정해도 이미 만든 작품과 적용본은 자동 변경되지 않는다.

## 필요한 자료

개인 VRM은 공개 APK에 포함하지 않는다. 기기의 **VRM 등록**에서 다음 파일을 등록한다.

| 자료 | 용도 | SHA-256 앞 12자리 |
|---|---|---|
| AvatarSample_E.vrm | 기준 얼굴·몸·의상과 기본 헤어 | ef6513de66ae |
| AvatarSample_E_Hair02.vrm | Hair02 헤어 추출 | f4df98833a83 |
| E-with-Hair02-proof-01.vrm | 이전 버전 자료 호환, Hair02 원본이 없는 경우 | c1853aa3c22b |

최초 준비는 몇 분 걸릴 수 있다. 파일 이름이 아니라 실제 내용으로 호환성을 확인한다. 이후 검증된 조합을 재사용한다.

향후 VRM을 추가로 제공하면 헤어 소유 영역·뼈대·기준 모델 호환성을 확인한 뒤 파츠와 사진 목록에 추가한다. **아무 VRM이나 자동 분리·교환하는 기능은 아니다.** 눈 모양·입·얼굴형은 자료 준비 안내만 표시하며, 아직 모양 교체를 제공하지 않는다.

## 원본과 저장 자료 보호

- 헤어 전용 JSON+BIN에 정점·재질·원본 이미지 바이트·뼈 연결·헤어 물리 데이터를 분리한다. Body 안의 뒤머리도 피부와 구분한다.
- 추출·조립 후 얼굴·몸·의상의 구조 지문, 헤어 지문과 해시를 비교한다. 완료된 결과만 게시한다.
- 원본 텍스처는 축소하지 않는다. 작은 이미지는 선택 목록의 사진에만 사용한다.
- 새 헤어가 실제로 표시된 것을 확인한 뒤 외형과 초안을 확정한다. 빠른 연속 선택에서는 마지막 요청만 반영한다.
- 처음 준비하는 중 다른 앱을 열어도 준비를 이어간다. VRM 등록 후 돌아오면 헤어 카드 목록을 다시 갱신한다.
- 파일·검증서 누락, 메모리 부족, 저장 실패는 오류로 처리하고 기존 캐릭터·작품을 보존한다.
- 기존 외형 v1과 새 파츠 외형 v2를 함께 읽는다. 원래 보관함의 선택 모델은 임의 변경하지 않는다.
- 파츠와 조합 모델은 앱 내부 `noBackupFilesDir/vrm-hair-parts` 및 기존 VRM 저장소에 보존한다. 원본·개인 사진·서명 키는 Git/APK/공개 배포에 넣지 않는다.

## 확인한 범위

API 36 휴대폰·태블릿 가상 기기에서 실제 두 모델을 사용했다. 20회 연속 교체, 빠른 선택, 독립 색상, 회전·뒤로 가기·앱 복귀, 실패 복구, 저장·다시 열기, 이전 형식 호환, 이미지 합성 및 별도 프로세스의 작품 복원을 검사했다. 실제 시스템 배경을 덮어쓰지 않고 적용본 저장소와 공통 배경 렌더러를 검사했다.

정면·측면·뒤쪽, 눈 깜빡임, 고개 움직임에 따른 헤어 물리를 확인했다. 사용되는 원본 이미지의 바이트/해상도와 보호 도형 지문을 비교하고, 렌더러 종료 시 그래픽 자원 반환도 검사했다.

Galaxy S26 Ultra / Tab S11 Ultra 실기기의 발열·절전·장시간 동작과 이번 외형의 실제 시스템 배경 적용은 별도 확인이 필요하다. 원본 화질 모델은 메모리를 많이 사용하며 준비 속도는 기기에 따라 다르다.

## 업데이트

기존 앱 위에 설치할 때는 **MagicCircleCharging-v1.23-local-update.apk**를 사용한다. Actions의 `debug.apk`는 임시 서명으로 기존 앱과 서명이 다를 수 있다. 설치 오류가 나도 앱을 먼저 삭제하지 말 것: 삭제하면 앱 내부의 모델과 작품이 함께 사라질 수 있다.
