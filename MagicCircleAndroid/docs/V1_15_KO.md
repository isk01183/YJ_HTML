# v1.15 — 내 화면 만들기

## 사용 방법

1. 첫 화면의 **화면 직접 만들기**에서 **배경화면/잠금화면** 또는 **충전 화면**을 선택합니다.
2. **파일 추가**로 JPG·PNG·GIF를 가져옵니다. **보관함**에서는 이미 가져온 파일을 다시 사용할 수 있습니다.
3. 레이어를 선택한 뒤 드래그로 이동하고, 크기·각도 슬라이더 또는 숫자 입력으로 정밀 조정합니다. 좌우 반전, 순서, 표시/숨김, 제거도 가능합니다.
4. 충전 화면에서는 배터리 %, 상태, 온도, 배터리 건강 상태, 연결 방식, 잔량 막대, 단계별 문구의 표시 여부와 위치를 바꿀 수 있습니다. **기본 복원**은 원래 디자인의 표시로 돌아갑니다.
5. 이름을 정하고 **저장**합니다. 저장만으로 현재 충전 화면이나 배경화면이 바뀌지는 않습니다. 각 선택 목록에서 작품을 선택하거나 **미리 보고 적용**을 누르세요.
6. 기존 마법진도 선택 화면의 **충전 정보 편집**에서 같은 방식으로 수정할 수 있습니다. 충전 표시 시간은 **1초 / 3초 / 5초 / 7초** 중 선택합니다.

기존 도안의 그림을 다시 그리거나 저해상도 이미지로 교체한 업데이트가 아닙니다. 기존 렌더러를 유지하면서 사용자가 올린 이미지 합성과 정보 편집을 추가했습니다.

## 꼭 알아둘 점

- 한 작품은 숨긴 항목을 포함해 최대 **8개 레이어**, GIF는 최대 **2개**입니다. 기기 메모리 보호를 위해 큰 원본은 표시용으로 축소해 읽습니다.
- GIF는 원래 속도로 재생합니다. 정지 배경화면은 첫 프레임을 사용합니다.
- 사진 자체에 그려진 숫자·글자는 따로 수정할 수 없습니다. 예를 들어 `69%`가 찍힌 사진 위에 실제 배터리 정보를 켜면 두 숫자가 겹칠 수 있습니다.
- 편집 중 화면을 회전하거나 앱이 재생성되어도 초안을 복원합니다. 이미지 가져오기 실패가 기존 작품을 지우지는 않습니다.
- 충전 정보 설정이 없는 도안은 원래 표시를 유지합니다. 모든 항목을 끄는 설정과 **기본 복원**은 서로 다릅니다.
- 표시 시간은 렌더러 준비가 끝난 뒤부터 계산합니다. 별도로 최대 2초의 준비 기한이 있으며, 준비에 실패하면 투명 상태로 종료하여 검은 창이 남지 않게 합니다.
- 충전선을 분리하면 종료합니다. 재연결은 새로운 렌더러로 처음부터 재생합니다. 접근성 서비스가 켜져 있어야 합니다.
- 적용된 라이브 배경화면은 작품을 수정·삭제해도 바뀌지 않도록 독립 복사본을 사용합니다. 안전을 위해 이전 복사본이 저장 공간에 남을 수 있습니다.
- Android 14 미만은 잠금화면의 라이브 배경화면 슬롯을 확실히 조회할 수 없어 사용한 슬롯을 재활용하지 않습니다. 후보 3개를 사용한 뒤에는 정지 배경화면을 이용해야 할 수 있습니다.
- 라이브 배경화면의 홈/잠금 대상은 Android 시스템에서 최종 선택합니다. 기기에서 해당 선택을 제공하지 않으면 정지 배경화면을 사용하세요.
- 인터넷 권한·새 외부 라이브러리·유료 API를 추가하지 않았습니다.

### 남은 확인 사항

PC에서 Gradle 빌드와 에뮬레이터를 동시에 사용했을 때 premium의 한 차례 콜드 로드가 2초 준비 기한을 초과해 표시 없이 종료했습니다. 충전 분리 시 정리되었고 앱 종료 오류는 없었습니다. 부하를 줄인 태블릿 재검사를 따로 수행했지만, 삼성 실기기의 절전·재부팅·잠금 상태와 저사양/고부하에서의 첫 로드는 별도 검증이 필요합니다. 이를 모든 기기에서 완벽히 해결했다고 주장하지 않습니다.

AST 전용 Graphify 업데이트를 실행했습니다. Kotlin 3개 파일(`MagicWallpaperService`, `UploadedWallpaperStore`, `WallpaperController`) 파서 경고는 남아 있습니다. 실제 Kotlin 컴파일과 검사는 통과했습니다.
