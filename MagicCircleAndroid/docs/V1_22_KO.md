# v1.22 — 실제 VRM 캐릭터 꾸미기

## 이번에 사용할 수 있는 기능

- 검증된 E 캐릭터의 기본 헤어 / E 몸·의상에 Hair02를 조합한 헤어 선택.
- 머리카락과 홍채를 각각 팔레트, RGB(0–255), HEX(#RRGGBB)로 변경. 부위별 원본 복원.
- 이름을 붙여 새 캐릭터 저장, 저장한 캐릭터 재편집, 저장값 복원, 초안 보관.
- 저장한 외형을 JPG·PNG·GIF 레이어와 합성하여 기존 배경화면 적용 흐름에 전달.
- 작품과 배경 적용본은 선택 당시 외형의 사본을 보관. 보관함 수정만으로 이미 만든 배경은 바뀌지 않음.

## 사용 순서

`VRM 보관함 → 캐릭터 꾸미기 → 헤어/머리색/눈 색상 → 이름 입력·저장 → 배경화면 만들기 → 이미지 추가·배치 → 미리보기 → 시스템 적용`

기존 배경 편집기에서도 **보관함에서 캐릭터 선택 → 저장한 VRM 캐릭터**로 선택할 수 있다. 원본 VRM 선택은 편집 외형을 제거하고 원래 재질을 사용한다.

개인 모델은 APK에 넣지 않는다. 기기에 다음 두 파일을 먼저 등록한다.

| 헤어 | 필요한 로컬 파일 | SHA-256 앞 12자리 |
|---|---|---|
| E 기본 | AvatarSample_E.vrm | ef6513de66ae |
| Hair02 | E-with-Hair02-proof-01.vrm | c1853aa3c22b |

Hair02 **전체 캐릭터**인 AvatarSample_E_Hair02.vrm은 위 조합 파일과 다르다. 이름만 같고 내용이 다른 파일은 편집 지원 대상으로 취급하지 않는다. 일반 VRM 불러오기는 기존처럼 별도 지원한다.

## 구현과 보존

- `VrmAvatarDefinition` / `VrmAvatarStore`: 모델 해시와 편집 캐릭터 ID 분리, 버전 검증, 원자적 저장.
- `avatar-dye.js`: 검증된 MToon의 머리·홍채 재질만 염색. 원본 명암·알파·해상도 유지, 동공·흰자·하이라이트 보호.
- `VrmAvatarActivity`: 실제 VRM 미리보기, 개별 색상 편집, 저장 목록. 헤어 썸네일은 해당 헤어를 처음 표시한 뒤 기기에서 생성한다.
- `ScreenScene` / `VrmSceneView`: 불변 외형 사본과 공통 렌더러. 같은 모델 색상 변경 시 기존 뷰 재사용.
- `VrmWallpaperStore`: 새 scene 적용본 v3, 기존 v1/v2 읽기 유지. 누락 모델·저장 실패 시 기존 작품/적용본 보존.
- 한 번에 한 모델을 편집한다. 원본 텍스처를 축소하지 않으며 메모리 부족 시 오류와 재시도를 안내한다.
- 새 서버·유료 API·추가 라이브러리 없음. 인터넷 권한 없음. 개인 VRM·텍스처·스크린샷·서명 키는 Git/APK에서 제외한다.

## 검증 범위와 한계

API 36 휴대폰/태블릿 에뮬레이터에서 독립 염색, 두 헤어 빠른 교환, 회전 후 초안/이름 복원, 새 이름 두 개 저장·수정·재열기, 이미지 합성, v1/v2/v3 저장 호환, 모델 누락과 저장 실패 보호를 검사한다. Node 검사와 Android 단위 검사·lint·APK 빌드도 배포 게이트다.

실제 Galaxy S26 Ultra/Tab S11 Ultra의 메모리·절전 정책과 새 편집 외형의 시스템 배경 적용은 별도 실기기 확인이 필요하다. 이번 자동 검사는 사용 중인 개인 배경을 덮어쓰지 않는다.

얼굴형·눈 모양·입 모양·체형·의상 파츠, 임의 VRM 간 모바일 헤어 조립과 VRM 내보내기는 **아직 구현하지 않았다**. 그에 맞는 파츠·변형 데이터를 준비한 뒤 확장한다. 이번 버전은 VRoid 전체 기능 완성판이 아니다.

배포 시 기존 앱 업데이트에는 `MagicCircleCharging-v1.22-local-update.apk`를 사용한다. Actions의 `debug.apk`는 임시 CI 서명으로 기존 앱과 서명이 다를 수 있다. 앱을 지우면 기기 내부 자료가 사라질 수 있으므로 업데이트 실패 시 삭제하지 말고 먼저 확인한다.
