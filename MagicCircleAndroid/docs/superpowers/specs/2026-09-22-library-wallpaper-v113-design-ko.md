# v1.13 — 마법진 정리·정지/라이브 배경화면 설계

상태: **2026-09-22 사용자 승인 완료**. 구현·검증 진행 중이며, 아직 전체 기능·실기기 테스트·APK 배포를 완료한 것이 아닙니다.

## 1. 목표와 개발 기준

원본의 구조·색감·광원 계층을 보존하면서 지정한 도안을 섬세하게 개선하고, 도안 관리와 W03·R01 배경화면 기능을 추가합니다. 사용자는 정지와 라이브 두 방식을 모두 선택했습니다.

- 기준: `codex/stellar-sanctuary-v112` 브랜치의 `ebc8932`, v1.12 / versionCode 15. 개발 전 Git 상태를 다시 확인합니다.
- 다음 배포는 v1.13 / versionCode 16입니다. 중간 배포가 생기면 실제 최신 번호보다 증가시킵니다.
- minSdk 23, 기존 세 언어(한국어·일본어·영어), 오프라인 사용, 업로드 자료를 유지합니다.
- 충전 연결 때 최대 7초 재생, 분리하면 즉시 종료, 재연결하면 처음부터 재생하는 기능은 별도로 유지합니다.
- 배경화면 적용은 사용자가 버튼을 누르고 확인할 때만 실행합니다. 충전 연결/분리 때문에 시스템 배경화면을 교체하지 않습니다. 잠금을 해제하거나 우회하지 않습니다.
- 추가 종량제 서비스, 유료 API, 계정/인증 설정 변경은 없습니다. 기존 파일 삭제와 main 병합도 하지 않습니다.
- 저해상도 참고 이미지를 확대하거나 회전시켜 완성품으로 사용하지 않습니다. 도형·룬·배경의 핵심 요소는 직접 그립니다.

## 2. 활성 도안: 43종

아래 목록을 v1.13 최초 적용 시의 활성 목록으로 사용합니다. 기존 내장 174종 중 나머지 131종은 삭제하지 않고 비활성화합니다.

```text
N01
C11 C12 C15 C16 C21 C22 C23 C26 C28 C30
W01 W02 W03 W04 W05
F01 F02 F03 F04 F05
A14 R01
crimson-abyss healing-wings snowflake sakura-seal spirit-bloom
chronos-gears fate-compass twilight-balance moon raphael
layered premium basic blue gold silver violet cyan core minimal
```

- 표시 코드 N01은 저장 ID `native-N01`, C/W/F/A/R 코드는 `ref-` 접두사를 붙인 기존 ID와 연결합니다.
- 요청의 `rapheal`은 실제 기존 ID `raphael`을 뜻하는 것으로 정리합니다. `basic`과 `classic`은 서로 다른 도안이며, 이번 활성 목록에는 `basic`만 포함합니다.
- 초기 목록 적용은 딱 한 번 수행합니다. 그 뒤 사용자가 활성/비활성 상태를 바꾸면 앱 재실행이나 업데이트가 이를 되돌리지 않습니다.
- 기존 업로드 파일은 내장 174종 집계에서 제외하며 그대로 보존합니다. 이번 내장 도안 정리 때문에 업로드 파일을 삭제하거나 숨기지 않습니다.

## 3. 화면과 사용자 지정 탭

첫 화면에는 `배경화면 변경`, `잠금화면 변경` 버튼과 기존 충전 서비스 상태·설정 진입을 둡니다. 아래에는 하나의 `마법진 선택` 영역을 둡니다.

- 기본 `전체` 탭에서 활성 내장 도안과 사용자 업로드를 함께 선택합니다. 기존 고정 분류 탭은 제거합니다.
- `+ 탭 만들기`로 사용자 분류를 추가하고, 이름 변경·도안 넣기/빼기·탭 삭제가 가능합니다.
- 하나의 도안을 여러 사용자 탭에 넣을 수 있습니다. 빈 탭도 유지합니다. 탭 삭제는 분류만 없애며 도안이나 업로드 파일을 삭제하지 않습니다.
- 탭 이름은 공백만으로 만들 수 없고, 앞뒤 공백 제거 후 40자 이내이며 중복 이름을 거부합니다. 이름을 HTML로 실행하지 않고 일반 글자로 표시합니다.
- 비활성화한 도안의 탭 소속은 보존하되 활성 선택 목록에서는 숨깁니다. 재활성화하면 이전 탭에 다시 표시됩니다.
- 별도 `비활성 도안 관리` 화면에서 코드·이름 검색, 정적 미리보기, 개별 활성화를 제공합니다. 기존처럼 전체를 한꺼번에 복원해야만 확인할 수 있는 방식은 사용하지 않습니다.
- 모든 도안의 코드가 목록과 상세 미리보기에 표시되어 수정 요청 대상을 분명하게 식별할 수 있어야 합니다.

## 4. 설정 저장·이전 규칙

기존 `MediaLibrary`의 원자적 저장(완전한 새 파일이 준비된 뒤 교체하는 방식)을 확장합니다. 별도 데이터베이스나 클라우드는 추가하지 않습니다.

- 기존 저장 파일을 덮기 전에 앱 전용 저장 공간에 v1 원본 복구본을 남기고, 스키마 버전을 올려 탭과 목록 적용 버전을 함께 저장합니다.
- 내장 활성 목록, 사용자 탭, 현재 충전 도안이 서로 모순되지 않도록 같은 저장 트랜잭션에서 갱신합니다. 파일 교체 전 쓰기 실패 시 이전 상태를 유지하고 오류를 표시합니다. 교체 후 결과를 확인하지 못한 경우에는 복원을 단정하지 않고 추가 쓰기를 막아 원본·복구본을 보존하며 확인 필요를 안내합니다.
- 업데이트 전 선택이 활성 도안 또는 유효한 업로드라면 유지합니다. 선택 도안이 이번 목록에서 제외되면 N01로 전환했다는 안내를 표시합니다. 사용자가 명시적으로 충전 도안을 비워 둔 상태는 유지합니다.
- 사용자가 현재 충전 도안을 비활성화하면 다음 활성 도안으로 전환하고 결과를 안내합니다. 남은 도안이 없으면 충전 연출을 끕니다. 임의로 숨긴 도안을 되살리지 않습니다.
- 저장 파일이 손상됐거나 알 수 없는 버전이면 초기화·삭제·자동 덮어쓰기를 하지 않습니다. 기존 자료를 보존하고 복구가 필요함을 안내합니다.
- 웹 화면에서 넘어오는 ID·탭 이름·적용 대상은 Android 쪽에서도 검증합니다. 알려진 도안과 앱이 보관하는 업로드 이외의 경로/URI는 받지 않습니다.
- 배경화면의 선택값은 충전 도안과 별도로 저장합니다. 도안 비활성화는 앞으로의 선택을 막는 동작이지, 이미 적용한 시스템 배경화면을 강제로 바꾸는 동작이 아닙니다.

## 5. 정지·라이브 배경화면

공통 흐름은 `홈 또는 잠금 선택 → W03/R01 선택 → 정지/라이브 선택 → 미리보기 → 적용 확인`입니다. 다른 도안에는 배경화면 적용 버튼을 활성화하지 않으며 Android 진입점에서도 두 ID만 허용합니다.

### 정지 배경화면

- W03/R01의 그리기 코드로 현재 화면에 맞는 고화질 결과를 생성합니다. 참고 PNG/JPG를 사용하는 것이 아니라 코드 렌더링 결과를 Android의 정지 배경화면 형식으로 전달합니다.
- 원형을 타원으로 늘리지 않고, 핵심 도형은 보존하며 여백은 같은 절차적 배경으로 채웁니다. 시계·잠금 UI와 겹칠 수 있는 영역은 미리보기에서 확인할 수 있게 합니다.
- Android `WallpaperManager`의 공식 홈/잠금 대상을 사용합니다. minSdk 23은 유지하되 잠금 전용 API가 없는 구버전에서는 해당 기능을 지원하지 않는다고 표시합니다. 잠금 대신 홈을 몰래 변경하지 않습니다.
- 이미지 생성과 저장은 화면을 멈추지 않게 처리하고, 해상도와 메모리를 제한합니다. 완료 여부는 실제 반환 결과와 오류를 확인하여 알립니다.
- 정지 배경화면은 실시간 배터리 수치를 갱신하지 않습니다. 오래된 배터리 수치가 남지 않도록 W03/R01 정지 출력에는 충전 전용 숫자·상태 문구를 넣지 않습니다.

### 라이브 배경화면

- 공식 `WallpaperService`와 시스템 적용 미리보기를 사용합니다. 접근성 오버레이를 계속 띄우는 방식으로 배경화면을 흉내 내지 않습니다.
- 매우 느린 룬/외곽 장식 움직임과 은은한 반짝임만 사용합니다. W03의 나무와 중심 구도, R01의 육엽 구조 및 내부 기하는 고정합니다. 충전용 7초 등장/퇴장 장면을 계속 반복하지 않습니다.
- 화면이 보이지 않거나 Surface가 사라지면 프레임 예약을 중단하고, 엔진 종료 시 관련 리소스를 해제합니다. 화면을 강제로 켜 두지 않습니다.
- 홈/잠금 라이브 적용 범위는 실제 Android·삼성 시스템이 제공하는 범위를 따릅니다. 잠금 단독을 지원하지 않으면 이를 안내하고 사용자가 정지를 선택할 수 있게 합니다. 동의 없이 홈 또는 홈+잠금으로 대체 적용하지 않습니다.
- 이번 버전은 홈과 잠금에 서로 다른 라이브 도안을 동시에 운용하는 기능까지 약속하지 않습니다. 시스템이 제공하는 단일 도안 적용 범위를 대상으로 검증합니다.
- 미리보기 임시 선택과 현재 적용 중인 설정을 구분합니다. 미리보기 취소가 현재 라이브 도안을 바꾸면 안 됩니다. 시스템 화면에서 돌아왔다는 사실만으로 성공이라고 표시하지 않습니다. 적용 확인이 불가능하면 확인 필요 상태로 남기고 기존 활성 설정을 보존합니다.
- 강제 종료·재부팅 후에도 시스템이 서비스를 다시 만들 수 있도록 저장된 설정만으로 렌더러를 복원합니다. 잘못된 설정은 검증된 기본 W03으로 안전하게 처리하되, 시스템 배경화면을 새로 설정하는 동작은 수행하지 않습니다.

- 기존 정밀 도형을 재사용하고 선의 접점 좌표를 공유합니다. 닫힌 도형은 실제로 닫힌 Path로 만듭니다.
- 주요 선·보조 선·넓은 광막을 분리합니다. 번짐으로 구조를 가리거나 광원 강도를 높인 것만으로 고품질이라고 판단하지 않습니다.
- 지정 도안별 원본/이전판/수정판 정적 비교와 실제 크기 확대 확인을 남깁니다. 광량·두께·접점·중심·배경 경계를 확인한 뒤 움직임을 검수합니다.
- 완전 동일하다는 수치나 평가를 임의로 만들지 않습니다. 남은 차이는 코드별로 기록하여 사용자가 앱에서 확인하고 수정 요청할 수 있게 합니다.
- 나머지 활성 도안은 현재 렌더링을 보존하고 목록·회귀 검증을 수행합니다. 이번 요청에 없는 모든 도안의 전면 재제작으로 범위를 확장하지 않습니다.

## 7. 렌더링 구성과 변경 접점

선택한 접근은 기존 구조를 보존하면서 필요한 두 도안의 배경화면 렌더러만 추가하는 방식입니다. 전체 OpenGL 재작성은 전 도안 회귀 위험과 작업 범위를 키우므로 기본안으로 채택하지 않습니다. Compose·Lottie를 사용했다는 이유만으로 화질이 높아지는 것도 아니므로 불필요한 새 의존성은 추가하지 않습니다.

- `gallery.html`, `gallery.js`, `i18n.js`: 첫 화면 버튼, 통합 선택 탭, 사용자 탭, 비활성 관리 UI와 세 언어.
- `MainActivity.java`, `MediaLibrary.java`, `ThemeSelection.java`: 화면 요청 검증, 설정 이전·저장, 활성 도안 선택.
- `ChargeStatusPanelRenderer.kt`와 관련 레이아웃: N01 중심 정렬. 단순 좌표 이동 전에 실제 충전 경로의 배치 원인을 확인합니다.
- `direct-circles.js`, `direct-extra.js`, `circle-designs.js`, `collection_circle.html`: 지정 도안의 벡터와 충전 화면 배경 연결.
- W03/R01 전용 Kotlin Canvas 렌더러: 기존 벡터의 구조와 경로를 옮겨 정지 출력·라이브 Surface·해당 도안의 앱 미리보기/충전에서 공유합니다. 기존 SVG 출력은 비교·이전용으로 남기되 실제 적용 화면을 두 벌로 따로 수정하지 않습니다.
- `WallpaperService`와 적용 진입점, Manifest 서비스/권한 선언: Android 공식 배경화면 생명주기와 시스템 확인 처리.
- `app/build.gradle.kts`, `.github/workflows/android-debug.yml`: 배포 버전과 CI 검증 기대값을 함께 증가시킵니다.

성능 원칙은 Path·Paint·Shader와 정적 레이어 캐싱, 프레임 내 할당 최소화, 하드웨어 가속 친화적 그리기입니다. 필요 시 코드로 생성한 레이어를 메모리에 캐시할 수 있지만 참고 이미지 파일로 대체하지 않습니다. BlurMaskFilter·강제 소프트웨어 레이어·숨겨진 API는 사용하지 않습니다. 화면 크기 변경 때 캐시를 다시 만들고 렌더링 중인 자원을 성급히 해제하지 않습니다.

라이브는 기본 최대 30fps로 제한하고 정적인 레이어는 매번 다시 계산하지 않습니다. API별 지원되는 Canvas 경로를 사용하며 새 셰이더 최적화가 필요해도 Canvas 폴백을 유지합니다. 라이브와 충전 오버레이가 동시에 뜨는 경우도 메모리·프레임·생명주기를 검사합니다. 충전 연결 감지 경로는 불필요하게 교체하지 않습니다.

## 8. 검증과 배포 완료 기준

1. **저장/목록:** 최초 활성 43·비활성 131, ID 오탈자 매핑, 이전 선택 유지/전환, 재시작 후 상태 유지, 탭 중복/삭제, 개별 복원, 저장 실패/손상 자료 보존을 자동 검사합니다.
2. **배경화면:** W03/R01 외 차단, 홈/잠금·정지/라이브 조합, 취소 시 기존 설정 유지, 권한/정책 제한, 비지원 대상 안내를 확인합니다. 정지 성공과 라이브 성공은 따로 기록합니다.
3. **시각:** 지정 수정 대상 모두 정적 비교. 작은 휴대폰/긴 휴대폰/태블릿·세로/가로, 한/일/영과 큰 글자 크기를 검사합니다. 참고 구조와 남은 차이를 함께 보고합니다.
4. **충전 회귀:** 앱이 전면·백그라운드인 경우 각각 재연결 반복, 7초 자동 종료, 재생 중 분리, 비행기 모드, 잠금/화면 꺼짐 상태를 실기기로 확인합니다. 시스템 잠금 동작을 우회하지 않습니다.
5. **안정성:** 라이브 보임/숨김 반복·화면 회전·재부팅, 충전과 동시 실행에서 크래시/ANR/지속 메모리 증가를 점검합니다. 실제 연결된 기기의 모델을 확인하고 S26 Ultra·Tab S11 Ultra의 검증과 구분합니다.
6. **빌드:** `testDebugUnitTest`, `lintDebug`, `assembleDebug` 및 관련 기존 자체 검사를 실행하고 결과를 기록합니다. 실행하지 못했거나 실패한 검사는 숨기지 않습니다.
7. **배포:** 기존 공개 저장소의 표준 GitHub Actions 무료 경로로 빌드합니다. 유료 실행기·서비스는 추가하지 않습니다. 기존 설치와 서명이 호환되는 테스트 APK와 CI APK를 구분하고 버전·SHA-256·다운로드 링크를 제공합니다. main에는 병합하지 않습니다.

문서 승인 뒤 구현 계획을 작성하고, 계획 검토와 실행 방식 선택을 거쳐 작업합니다. 완료 보고에는 수정 파일·실행한 검사·실기기별 검증 범위·남은 시각 차이를 한국어로 짧게 정리합니다.
