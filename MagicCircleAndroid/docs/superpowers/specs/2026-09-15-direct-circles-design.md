# 118종 직접 그리기 및 S26 Ultra 재연결 진단

## 승인된 기준
2026-09-15 사용자는 HTML/CSS/JS로 직접 그리는 방식과 대표 3종 비교 후 전체 118종으로 확대하는 제작 방향을 승인했다. 같은 요청에서 연결된 S26 Ultra의 충전 재연결 미재생 수정도 요청했다.

### 원본 재현 기준 — 사용자 정정 반영 (2026-09-20 재개)
- 사용자가 요구한 수준은 비슷한 분위기의 독립 도안이 아니라 제공한 원본의 재현이다. 현재 C03/R01/W03 비교판의 기술 검증 통과는 시각 품질 합격이 아니다. 세 도안 모두 재현 품질 미달이며 수정 대상이다.
- 원본과 다른 임의 룬, 중심 문양, 가지/잎/뿌리 생략을 알려진 차이라고 적는 것만으로 요구사항을 충족했다고 처리하지 않는다. 개별 도안의 외곽/내곽 반지름, 중심 위치, 교차 관계, 획과 장식 배치, 색과 발광을 실제 원본에 맞춘다.
- C03 원본은 180×178픽셀이고 확대 참고본에는 새 세부 정보가 없다. 판독 불가능한 획을 임의 문양으로 채워 동일 재현이라고 주장하지 않는다. 더 선명한 원본/벡터가 필요한 구간과 현재 자료에서 실제 확인 가능한 구간을 구분한다.
- 원본과 일치하지 않은 상태에서 다른 115종으로 같은 단순화를 일괄 확장하거나 APK에 완성 도안으로 넣지 않는다. 기존 앱은 그대로 보존한다.

## 범위와 제작 단계
- 목표 전체 118종: A/B/C 90, E 8, U 4, F/G 10, W 5, R01 1. 서로 같은 모티브의 변형은 보존하되 새 고유 모티브라고 과장하지 않는다.
- 첫 품질 확인 대상은 C03, R01(육엽), W03(세계수). 세 가지 실제 코드 도안의 정적 비교와 수동 애니메이션 미리보기를 제공한다. 사용자가 구조를 확인하기 전 나머지를 검수 완료로 표시하거나 기존 앱의 118종을 일괄 교체하지 않는다.
- C03/R01의 확인 가능한 수치 기하는 재사용한다. 색상 등고선 자동 추적, 큰 SVG를 img로 표시, PNG/JPG/GIF 배경 위 입자만 얹는 방식은 새 마법진 구현으로 인정하지 않는다.
- 원·호·곡선·도형·룬은 HTML 내부의 SVG DOM과 JS 좌표 데이터로 만든다. CSS/JS는 개체별로 움직인다. 외곽 링 / 룬 / 기하 / 코어 / 궤도 / 입자 / 배경을 분리한다.
- W03 줄기·가지·잎·꽃·달·장식도 수작업 경로/좌표로 다시 구성한다. 단순 임의 프랙털 나무로 바꿔놓고 동일하다고 말하지 않는다. 원본 구도와 지배적인 가지·꽃 위치를 비교한다.
- 큰 별과 세계수 줄기는 고정. 선 그리기→코어 점등→느린 장식/입자→퇴장. 최대 7000ms. 강한 섬광 없음. 모션 축소 지원. 원의 종횡비 유지, 경로 닫힘·공유 접점 검증.
- 불분명한 룬/원본 뒤에 가려진 선은 판독 확정이라 주장하지 않고 도안별 제한으로 표시한다. 원본 사진/설명은 비교 화면에만 표시 가능하다.
- 기존 55종, ko/ja/en, 개인 파일 업로드·삭제/숨김/복원, 오프라인, 접근성/잠금 보호를 유지한다. 추가 라이브러리·유료 API·인증 변경 없음.

## 충전 재연결 오류
실기기 앱 버전·접근성 바인딩·전원 이벤트·WebView 로딩/시작/정리 로그를 먼저 수집한다. 장치가 ADB에 없으면 USB 디버깅 허용을 요청하고 임의의 서비스 재시작/권한 변경/배터리 시뮬레이션으로 덮지 않는다. 원인 증거가 확인된 뒤 실패 재현 테스트→최소 수정→같은 기기 재연결 확인 순서로 진행한다.
